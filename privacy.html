Política de privacidad — Gmail Tools

Última actualización: 27 de octubre de 2026

Gmail Tools es una herramienta personal de un único usuario, Hernando Gaitán, que la usa con sus propias cuentas de Gmail. No se ofrece a terceros.

Datos a los que se accede

Con la autorización del propietario de la cuenta, la herramienta accede a mensajes, etiquetas, borradores y filtros de las cuentas de Gmail del propio usuario, usando los permisos gmail.modify y gmail.settings.basic.

Cómo se usan los datos

Los datos se usan solo para las acciones que el usuario solicita: buscar, leer, redactar, enviar y organizar correo. No se usan para publicidad, no se venden y no se transfieren a terceros. No se usan para entrenar modelos de inteligencia artificial generalizados.

Almacenamiento y seguridad

La herramienta se ejecuta en el computador del usuario y no tiene servidores propios. Los tokens de autorización se guardan localmente en ese equipo. El contenido de los correos solo se procesa en la sesión de trabajo del usuario con su asistente de IA, y no se conserva en una base de datos propia.

Retención y eliminación

El usuario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions y borrando los archivos de credenciales locales. Al revocarlo, la herramienta deja de tener acceso.

Cumplimiento

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

English summary: Gmail Tools is a single-user personal tool. It accesses only the owner's own Gmail data, on his own computer, to perform actions he requests. Data is not sold, shared, or used for advertising or to train generalized AI models. Access can be revoked at any time at myaccount.google.com/permissions.
